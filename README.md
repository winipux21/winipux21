## 🚀 Проекты

| 🏷 | Проект | Кратко |
|---|---|---|
| 🆘 | **SMP (Search Missing Persons)** | Full-stack платформа для координации поиска пропавших людей: REST-API, JWT-аутентификация, интерактивные карты Yandex и WebSocket-чат для волонтёров. |
| 📱 | **SMP VK Mini App** | Версия SMP в экосистеме VK: отчёты, карта и чат прямо в мобильном клиенте; бэкенд — Node.js + MongoDB, фронтенд — React + VKUI. |

| 📚 | **Cyber-Referent** | Веб-сервис + Telegram-бот для проверки, исправления и конвертации библиографических ссылок (GOST/APA/MLA) c AI-дополнением метаданных. |
| 🎞 | **YouTube Videos Downloader** | Скрипт на Python для скачивания видео с YouTube в любом доступном качестве. |
