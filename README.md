## 🚀 Проекты

| 🏷 | Проект | Кратко |
|---|---|---|
| 🆘 | **SMP (Search Missing Persons)** | Full-stack платформа для координации поиска пропавших людей: REST-API, JWT-аутентификация, интерактивные карты Yandex и WebSocket-чат для волонтёров. |
